# Store mode, rebuilt to the new design

Taken with local test data in a throwaway database. Phone (390 px), in French except the first one, which is English. Store mode is the phone's shopping view; it is not drawn on a computer, so there is no desktop shot.

- `phone-en-1-dark-default.png`: dark, nothing switched on: the count, the pink bar, All / Aisle / Hide done, a sticker for each store with its "N LEFT" badge.
- `phone-fr-2-dark-aisle.png`: Aisle on, each store's items under the name of their section.
- `phone-fr-3-dark-store-folded.png`: a store folded away by its sticker (its count stays).
- `phone-fr-4-light-checked.png`: light theme, two items checked (they fade, are struck through and stay in place).
- `phone-fr-5-leave-sheet.png`: « ← Liste » with items checked.
- `phone-fr-6-colours-sheet.png`: the store colours (wheel and hex / RGB box).
- `phone-fr-7-inventory-confirmation.png`: « Ajouter à l'inventaire » opens the Inventory confirmation first.
- `phone-fr-8-added-sheet.png`: after confirming.
- `phone-fr-9-confetti.png`: the whole list checked.
- `phone-fr-10-move-sheet.png`: press and hold an item: « Déplacer … vers » lists the stores (the one it is in is greyed).
