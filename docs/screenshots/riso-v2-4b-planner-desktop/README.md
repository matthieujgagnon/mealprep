# Riso v2 (4b): the desktop Planner, second pass

Screenshots of the desktop Planner with local test data (the recipes, Inventory and planned week were put
in a throwaway database for the pictures; none of it is in the app, and the recipe photos are plain
colour tiles).

Desktop (1280 px), English:
- `planner-desktop-en.png`: the whole page. The week's dates over the title, the arrows and the week pill at the right; the board with today's header pink, the weekend as a dotted pink block that also takes in Friday supper (an L-shaped segment), the legend with "Make the grocery list"; the "how it works" card; the finder.
- `planner-desktop-en-weekend-menu.png`: the "WEEKEND ▾" tag's menu: show/hide, days, the evening before, presets.
- `planner-desktop-en-slot-card.png`: an empty slot's card beside it, on the Note tab with the quick notes and Save.
- `planner-desktop-en-planned-card.png`: a planned meal's card: the preview, then Cook, Use as a base for other meals, Replace this recipe.
- `planner-desktop-en-week-calendar.png`: the week pill's month calendar.
- `planner-desktop-en-slot-picker.png`: the slot picker after a result's + with no slot chosen.
- `planner-desktop-en-toast.png`: the message with Undo after adding.
