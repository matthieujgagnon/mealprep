Grocery list

The approved Grocery page, built on row 6a. What the live code draws today is in the archive. Every checkbox is clickable and shared between English and French: once for bought, twice to queue for inventory, three times to put it back. Each store adds its queued items with one button at the bottom.

  • Desktop rows use one grid: check, name, On sale, Recipe, Buy, ×. The store header labels the columns.
  • The sale price links to the Deal card. In By aisle and By recipe the store name follows the price.
  • The number is a 52 × 36 pill instead of the 42px round number.
  • No + Inventory button on rows. Queued rows turn pale blue and get a blue + in the box.
  • Item names always start with a capital. Items you added yourself say "Added by you" in faint type under the name.
  • On a phone the cart is a small pink bar under the How it works box (above the add field when the box is dismissed) instead of the big card in the side column.
  • Phone keeps its baseline layout but uses the same three-step checkbox and store footer.
