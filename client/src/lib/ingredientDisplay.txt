# What an ingredient is called in English and in French (Quebec).
#
# The app uses this to SHOW a recipe's ingredient names in the language you picked
# (FR | EN). It never changes the recipe: the text saved with the recipe stays exactly
# as it was written, and a name that is not here is shown as written.
# Code: lib/ingredientDisplay.js. The admin's Ingredient names card lists the names from the recipes
# that have no line here yet.
#
# ---------------------------------------------------------------------------------
# [ingredients]  one line per ingredient:
#
#     English singular | English plural | French singular | French plural | gender
#
#   * gender is m or f (masculine, feminine). Add p when the French name is always
#     plural (« épinards », « pâtes »): mp, fp. It is used to make the describing words
#     and prep words agree: « oignons rouges », « tomates hachées », « pois surgelés ».
#   * "=" in a plural column means the plural is the same as the singular.
#   * "/" gives other spellings that are understood when the name is READ. The first
#     one is the one that is SHOWN. « coriandre » is shown for cilantro AND coriander.
#   * Write each form the way it is said in a Quebec kitchen (bleuets, sauce soya,
#     poudre à pâte, cassonade, yogourt).
#   * Describing words (fresh, red, boneless, frozen...) are NOT repeated on every line:
#     "red onion" is "onion" + "red", so « oignon rouge » needs no line. Add a whole line
#     only when the pair is not just the two parts put together ("green pepper" is a
#     bell pepper, not a pepper that is green).
#
# Every line is checked against the matcher (lib/inventoryMatch.js) by
# ingredientDisplay.test.js: English and French of a line must be the same food to it.
# ---------------------------------------------------------------------------------
